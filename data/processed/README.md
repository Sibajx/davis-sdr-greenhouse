# Processed data

This folder is reserved for the processed datasets of the field evaluation
(29 Aug – 4 Sep 2026) reported in the paper. It is currently empty: the
figure scripts read the daily files from `data/raw/` directly (see
`data/raw/README.md` and `docs/REPRODUCIBILITY.md`, section 2.2).

The phase-1 test dataset (12–16 June 2026) was removed from the repository
because it is not the paper's data. It remains in the git history.

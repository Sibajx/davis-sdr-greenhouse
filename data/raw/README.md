Esta carpeta es para payloads hexadecimales crudos o capturas de tramas RF sin
procesar (ej. muestras usadas para validar el CRC-16 y el decodificador de
bits). Actualmente no se incluye ningún archivo aquí; se puede agregar una
muestra pequeña de tramas de ejemplo si se desea acompañar el repositorio con
datos de prueba para el decodificador.

# Figuras exploratorias

`graficas.pdf` contiene gráficas exploratorias adicionales (en español) sobre
el mismo dataset de campo: perfiles termodinámicos promediados de 3 días
(12–14 junio 2026), relación temperatura vs. humedad, y relación radiación
solar vs. índice UV. Estas figuras **no forman parte del manuscrito final**
(`paper/IJSAMI.pdf`), pero se conservan aquí como material de análisis
complementario/interno.

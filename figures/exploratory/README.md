# Exploratory figures

`graficas.pdf` contains additional exploratory plots (originally produced
in Spanish) over the same field dataset: thermodynamic profiles averaged
over 3 days (June 12-14, 2026), temperature vs. humidity relationship, and
solar radiation vs. UV index relationship. These figures are **not part of
the final manuscript** (`paper/IJSAMI.pdf`), but are kept here as
complementary/internal analysis material.
